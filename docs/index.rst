EventLAB - Localization documentation
=====================================

EventLAB - Localization is standardizing neuromorphic and event-based localization techniques. This documentation will guide you through
the use of EventLAB - Localization to run the available baselines and datasets, as well as a detailed guide on contributing your own
baselines and datasets to the project.
